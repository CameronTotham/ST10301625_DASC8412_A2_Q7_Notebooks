# DASC8412 Assignment 2: Question 7 GenAI Notebooks

Cameron Totham (ST10301625)

This repository contains the Python code generated by two generative AI models for Question 7 of DASC8412 Assignment 2, executed on the provided dataset.

| Notebook | Model | Shared conversation |
| --- | --- | --- |
| `ChatGPT_Generated_Code.ipynb` | ChatGPT (OpenAI, standard chat interface) | https://chatgpt.com/share/6acf64ec-285c-83ea-adc7-66fbb7ddaf8f |
| `Gemini_Generated_Code.ipynb` | Gemini (Google, Auto mode) | https://share.gemini.google/BXa0YQKnGrry |

Both models received the same prompt, with `School_Data_CSV.csv` attached. Each notebook starts with the prompt, followed by the model's code exactly as generated, split into cells at the code's own section comments. The saved outputs show the charts each script produced.

The Gemini notebook also contains the five exploratory cells Gemini ran on the file before answering. Its first cell raises a `UnicodeDecodeError` because it reads the file as UTF-8; this is kept because it is why Gemini then tested other encodings.

## Dataset

`School_Data_CSV.csv` is not included in this repository. Download it from:

Combrink, H., Carr, E., de Wet, K., Marivate, V. and Rosman, B. 2023. *South Africa Education Data and Visualisations*. University of the Free State. https://doi.org/10.38140/ufs.22081058.v4 (licence: CC BY 4.0)

Place the CSV in the same folder as the notebooks to re-run them.

## Environment used

Python 3.13.5, pandas 3.0.5, Matplotlib 3.11.1, seaborn 0.13.2.
